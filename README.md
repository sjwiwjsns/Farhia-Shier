# Sky Rider - 3D Airplane Game

A fully playable 3D airplane flying game that runs in any modern browser. Works on desktop and mobile with no install needed.

## Play it

Just open `index.html` in a browser. On mobile, host it (e.g. GitHub Pages) and load the URL.

## Controls

**Mobile / Touch**
- Left on-screen joystick: steer (up/down to pitch, left/right to roll & turn)
- `+` button: speed up
- `-` button: slow down

**Desktop / Keyboard**
- Arrow keys or `WASD`: steer
- `Shift`: speed up
- `Ctrl`: slow down

## Goal

Fly through the golden rings scattered across the sky. Each ring is +100 points, and every 5 rings gives you +10 seconds. You have 90 seconds. Don't hit the ground!

## Tech

- Three.js (loaded from CDN via ES module import map) — no build step
- Single self-contained `index.html`
